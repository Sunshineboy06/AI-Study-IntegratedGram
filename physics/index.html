☁ 多终端同步（GitHub Gist）

进度存进你自己的私密 Gist，手机 / 平板 / 电脑输入同一组令牌 + 同步码即可共享。
在 GitHub → Settings → Developer settings → Personal access tokens 新建一个 fine-grained token，Repository access 选 Public repositories 即可，Permissions 里把 Gists 设为 Read and write。令牌只保存在这台设备的浏览器里，不会上传给任何第三方。
用于在不同设备间定位同一份数据，建议带点个人特征避免与他人重复。
